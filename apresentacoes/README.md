# Apresentações

Área para organizar apresentações, roteiros de slides, ideias de carrosséis e materiais executivos.

## Categorias

| Categoria | Exemplos de materiais |
|---|---|
| Inteligência Artificial | Agentes, ferramentas, prompts, produtividade, automação |
| Product Management | Discovery, delivery, métricas, roadmap, portfólio, BCP |
| Dados | Engenharia de dados, analytics, dashboards, IA aplicada |
| Carreira | Transição para PM, currículo ATS, LinkedIn, cases |
| Itaú / Produto | Jeito Itaú de Produtar, Semana de Produtos, desafios e aprendizados |

## Padrão recomendado para cada apresentação

Cada apresentação pode ser documentada assim:

```text
apresentacoes/
└── tema-da-apresentacao/
    ├── README.md
    ├── roteiro.md
    ├── slides.md
    ├── referencias.md
    └── imagens/
```

## Checklist de qualidade

- [ ] Título claro e direto.
- [ ] Mensagem principal em até 1 frase.
- [ ] Público-alvo definido.
- [ ] Estrutura: contexto, problema, solução, exemplo e próximos passos.
- [ ] Visual limpo e profissional.
- [ ] Linguagem simples.
- [ ] Dados ou evidências quando possível.
- [ ] Call to action final.
