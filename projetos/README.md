# Projetos

Área para registrar projetos práticos, sites, protótipos, automações, estudos e produtos digitais.

## Como organizar cada projeto

Cada projeto deve ter uma pasta própria, seguindo este modelo:

```text
projetos/
└── nome-do-projeto/
    ├── README.md
    ├── imagens/
    ├── apresentacao/
    ├── links.md
    └── aprendizados.md
```

## Critérios para documentar um projeto

Para cada projeto, registrar:

1. Problema que o projeto resolve.
2. Público-alvo.
3. Ferramentas utilizadas.
4. Passo a passo de construção.
5. Prints, links ou evidências.
6. Resultado esperado ou resultado medido.
7. Aprendizados.
8. Próximas melhorias.
