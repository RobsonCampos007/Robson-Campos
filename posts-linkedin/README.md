# Posts para LinkedIn

Área para organizar ideias, rascunhos, posts prontos, carrosséis e conteúdos educativos para LinkedIn.

## Objetivo

Transformar estudos e experiências em conteúdo profissional sobre IA, Produto, Dados, carreira e produtividade.

## Estrutura sugerida

```text
posts-linkedin/
└── ano-mes-tema/
    ├── post.md
    ├── carrossel.md
    ├── referencias.md
    └── imagens/
```

## Temas de conteúdo

| Tema | Possíveis posts |
|---|---|
| IA para produtividade | Ferramentas que ajudam no trabalho, estudo e organização |
| Agentes de IA | O que são agentes, exemplos simples e aplicações reais |
| Produto | Discovery, delivery, roadmap, métricas e priorização |
| Dados | Como dados ajudam na tomada de decisão |
| Carreira | Transição para PM, AI Product Manager e Data Product Manager |
| Aprendizado | Resumos de cursos, eventos, aulas e workshops |

## Modelo simples de post

1. Gancho inicial: frase forte ou pergunta.
2. Contexto: por que isso importa.
3. Explicação simples: analogia ou exemplo.
4. Aplicação prática: como usar no trabalho.
5. Aprendizado pessoal.
6. Chamada para conversa.
